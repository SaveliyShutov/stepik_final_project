# Stepik final project: Page Object autotests

Final project for the Stepik course "Автоматизация тестирования с помощью Selenium и Python".
Autotests for http://selenium1py.pythonanywhere.com/ written with the Page Object pattern.

Run the tests for review:

    pip install -r requirements.txt
    pytest -v --tb=line --language=en -m need_review
